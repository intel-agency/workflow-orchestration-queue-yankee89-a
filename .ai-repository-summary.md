# AI Repository Summary: workflow-orchestration-queue (OS-APOW)

## Overview

**workflow-orchestration-queue (OS-APOW)** is a headless agentic orchestration
platform that transforms GitHub Issues into autonomous AI execution orders.
The system shifts AI from a passive co-pilot to an autonomous background
production service.

## Architecture

The system follows a **4-Pillar Design**:

| Pillar | Component | Description |
|--------|-----------|-------------|
| The Ear | **Notifier** | FastAPI webhook receiver for GitHub events |
| The State | **Queue** | GitHub Issues as database with label-based state machine |
| The Brain | **Sentinel** | Async Python background service for polling and dispatch |
| The Hands | **Worker** | DevContainer with opencode CLI for code execution |

## Tech Stack

- **Language:** Python 3.12+
- **Framework:** FastAPI
- **Package Manager:** uv (Astral)
- **Testing:** pytest + pytest-asyncio
- **Linting:** ruff
- **Type Checking:** mypy (strict mode)
- **Containerization:** Docker, Docker Compose

## Project Structure

```
src/
  orchestrator_sentinel.py   # Sentinel: polling, claiming, dispatch
  notifier_service.py        # Notifier: FastAPI webhook receiver
  models/
    work_item.py             # WorkItem, TaskType, WorkItemStatus
    github_events.py         # Webhook payload schemas
  queue/
    github_queue.py          # ITaskQueue + GitHubQueue
tests/
  conftest.py                # Shared fixtures
  unit/                      # Unit tests
  integration/               # Integration tests
```

## Task State Machine

Issues transition through these label-based states:

```
agent:queued → agent:in-progress → agent:success
                                 → agent:error
                                 → agent:infra-failure
```

## Key Dependencies

- `fastapi` — Web framework for the Notifier service
- `uvicorn` — ASGI server
- `pydantic` — Data validation and settings management
- `httpx` — Async HTTP client for GitHub API calls

## Environment Variables

### Required
- `GITHUB_TOKEN` — GitHub PAT or App Installation Token
- `GITHUB_ORG` — Target organization name
- `GITHUB_REPO` — Target repository name

### Optional
- `SENTINEL_BOT_LOGIN` — Bot account login for distributed locking
- `WEBHOOK_SECRET` — HMAC secret for webhook verification
- `POLL_INTERVAL` — Polling interval in seconds (default: 60)
- `MAX_BACKOFF` — Max backoff on rate limits in seconds (default: 960)
- `HEARTBEAT_INTERVAL` — Heartbeat comment interval in seconds (default: 300)
- `SUBPROCESS_TIMEOUT` — Subprocess hard timeout in seconds (default: 5700)

## Development Commands

```bash
# Install dependencies
uv sync --extra dev

# Run tests
uv run pytest

# Lint
uv run ruff check src tests

# Format
uv run ruff format src tests

# Type check
uv run mypy src

# Run sentinel locally
uv run python -m src.orchestrator_sentinel

# Run notifier locally
uv run uvicorn src.notifier_service:app --reload
```

## Docker Services

```bash
# Start all services
docker compose up

# Start sentinel only
docker compose up sentinel

# Start notifier only
docker compose --profile phase2 up notifier
```
